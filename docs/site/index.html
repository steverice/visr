Unofficial · Free · Open source

Halo: Combat Evolved, native on Apple devices.

VISR ports the community decompilation of the original Xbox game to iPhone, iPad, Apple Vision Pro, Apple TV and the Mac. It runs the game's own code, compiled for Apple silicon. You bring your own disc.

Platforms

  • iPhone and iPad

    Native resolution, on-screen touch controls you can hide, and any game controller. OpenGL ES by default, or Metal with MetalFX upscaling.

    iOS and iPadOS 16 or later

  • Apple Vision Pro

    Plays in a window with a game controller, rendered with Metal at the window's resolution. Theater mode puts the picture on a screen in an immersive space.

    visionOS 2 or later · theater mode on visionOS 26

  • Apple TV

    Plays with a game controller and imports your disc image over the local network.

    tvOS 16 or later · less tested

  • Mac

    The same app, built for Mac Catalyst.

    Apple silicon · less tested

Planned Stereo rendering on Apple Vision Pro, with foveated rendering, is in development and not released yet.

Bring your own disc

VISR contains the decompiled game code and nothing else of the game. It ships no maps, sounds, textures, videos or fonts from the disc.

To play, you need a disc image (.iso or .xiso) of the original Xbox release of Halo: Combat Evolved, made from a disc you own. The app checks it and imports the maps on your device.

  • NTSC-US map build 01.10.12.2276
  • PAL map build 01.01.14.2342
  • PC, Custom Edition and Master Chief Collection files are not supported

Get started

There are no prebuilt releases yet. Build VISR on an Apple silicon Mac with Xcode, then sign it with your own Apple account.

  1. Install the tools

    brew install cmake ninja llvm lld sdl3 pkgconf

  2. Clone and build

    git clone https://github.com/steverice/visr.git
cd visr
python3 tools/ios_build.py --team YOUR_TEAM_ID \
  --bundle-id com.yourname.visr

  3. Import your disc

    Open VISR, tap Choose Halo XISO and pick your disc image in Files. The game starts when the import finishes.

The build and install guide covers the simulator, Apple Vision Pro, Apple TV, the Mac and troubleshooting.
