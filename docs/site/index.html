Halo: Combat Evolved on Apple Vision Pro

VISR is a native port of Halo: Combat Evolved to Apple Vision Pro, built from the game's decompiled code. It renders natively in Metal, with no emulation in between, so it holds the headset's frame rate in foveated stereo. The goal is the best possible, best-optimized Halo on Vision Pro, true to the original game.

VISR on GitHub

VR

  • Full stereo VR with head tracking, through Compositor Services
  • Foveated rendering through the Compositor's rate maps
  • The HUD in CE's own corners, out in the periphery
  • Scope zoom fills the view
  • Third-person cutscenes on a 3D screen in the room

VISR also plays in 2D, in a window or on a virtual screen in the room.

Get it

Installing, setup and configuration are in the README on GitHub. You need your own copy of the original Xbox game.
